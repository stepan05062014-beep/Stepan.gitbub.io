ЧАТ
ГЛАВНОЕ: КАК ОТКРЫВАТЬ ФАЙЛ

Онлайн не работает, если открыть игру двойным кликом по файлу (адрес вида file:///C:/...). Браузер блокирует сеть в таком режиме.

Нужно открыть игру по адресу http://localhost или с сайта (https://). Способы ниже.

СПОСОБ 1 — ЛОКАЛЬНЫЙ СЕРВЕР (проще всего)
  1. Установи Python (python.org) или Node.js.
  2. Открой папку с игрой, в адресной строке проводника напиши cmd и нажми Enter.
  3. Введи команду:
    python -m http.server 8000 или для Node: npx serve -l 8000
  4. Открой в браузере http://localhost:8000/index.html
  5. Теперь кнопка онлайна работает.
СПОСОБ 2 — БЕСПЛАТНЫЙ ХОСТИНГ

Закинь index.html и part2.html на GitHub Pages, Netlify Drop или itch.io — получишь ссылку https://…, по которой онлайн работает у всех без настройки.

НУЖЕН ЛИ RADMIN VPN?

Обычно — нет. Соединение идёт напрямую между браузерами (P2P), посредник нужен только для «рукопожатия».

Radmin VPN пригодится, если:

  • строгий NAT у провайдера и подключение не устанавливается;
  • вы в разных сетях и код комнаты «висит» без результата;
  • корпоративный/школьный Wi-Fi режет WebRTC.
Как с ним: оба ставят Radmin VPN → создают/вступают в одну сеть → хост поднимает локальный сервер (способ 1) → остальные открывают http://IP-хоста:8000/index.html (IP виден в окне Radmin VPN) → дальше обычный код комнаты.
ЧТО ДАЁТ ОНЛАЙН
  • Общий чат рыбаков
  • Все видят твои редкие уловы в реальном времени
  • Таблица лидеров по деньгам и уровню
  • Твой прогресс остаётся только твоим — ничего не сбрасывается
ЕСЛИ НЕ ПОДКЛЮЧАЕТСЯ
  • Проверь, что адрес начинается с http://localhost или https://
  • Код вводится точно как у хоста, регистр не важен
  • Хост должен держать вкладку открытой
  • Отключи VPN/прокси или наоборот включи Radmin VPN
  • Попробуй другой браузер (Chrome, Edge, Firefox)
